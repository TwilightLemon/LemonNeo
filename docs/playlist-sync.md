# 歌单单向同步

桌面端导入远程歌单或本机文件夹时，可勾选「自动跟随来源更新」。未勾选时保持一次性导入，已有歌单也不会自动开启同步。

## 自动与手动同步

- 启动完成后在后台检查一次，运行期间每 15 分钟检查一次。
- 歌单的「更多」菜单提供「立即同步此歌单」及单独暂停、恢复自动同步。
- 「工具与信息 → 音乐库」页签提供「立即同步所有歌单」及暂停、恢复所有自动同步；About 始终位于最后。
- 页签顶部展示歌单数、独立曲目数、歌单项总数和已知总时长；独立曲目按歌曲 ID 去重，时长仅累计一次且排除未知时长。
- 同步列表包含所有已关联来源的歌单（含已暂停的歌单），显示名称、来源和曲目数，可通过每行开关配置自动同步。全局暂停不会修改这些独立设置。
- 暂停只影响自动检查，手动同步仍然可用，也不会改变暂停设置。
- 全局暂停独立于每个歌单的暂停状态。恢复全部自动同步时，单独暂停的歌单仍保持暂停。
- 暂停设置、来源关联和最近成功检查时间保存在当前音乐库中，重启后仍然有效。

同步更新歌曲的新增、移除、顺序和来源信息，保留歌单 ID、已有歌曲条目 ID 和 LemonNeo 补全的外部 ID。
当前播放队列保持原状。文件夹同步只调整歌单记录，不会修改、移动或删除音频文件。
文件夹按路径排序；导入时填写的歌单名称、描述作为本地标签保留。

## 本地编辑

同步歌单的成员列表、排序、名称及原生歌曲 ID 跟随来源，暂停期间也保持这些限制。
无论是否同步，均可执行整单或单曲 Match、增删及修改外部 ID。
匹配后的元数据和手动修改的外部 ID 在后续同步及重启后保留；主动移除的外部 ID 也不会被来源重新添加。
歌单详情仅显示简短的同步状态，悬停可查看来源、最近检查时间和错误详情。「更多」菜单提供：

- 「创建可编辑副本」：创建普通本地歌单，原同步歌单继续跟随来源。
- 「转为本地歌单」：保留当前内容并解除来源关联，后续可自由修改。
- 「删除歌单」：删除本地歌单及关联，不影响来源，也不会自动重新创建。

应用服务保护成员增删、排序、名称和原生歌曲 ID；控制台匹配和外部 ID 编辑也遵循同样规则。
播放过程中补全歌曲外部 ID 仍然可用。

## 失败和完整性

网络异常、账号变更、来源不可访问、文件夹断开或快照不完整时，保留最后成功同步的内容，并显示错误。
只有来源明确确认完整的空歌单，才会清空本地同步歌单。切换账号后，需要登录原账号才能继续同步其歌单。
读取期间发生暂停、删除、解除关联或切换音乐库时，会丢弃已失效的读取结果。

插件的 `RemotePlaylist.IsComplete` 默认为 `false`。插件只有在成员列表、顺序和歌曲详情完整时才能设为 `true`；
分页未取完、详情缺失、解析丢失条目及无法确认总数时必须保持 `false`。普通一次性导入仍允许不完整的结果。
网易云插件根据完整 `trackIds` 及详情判断，QQ 音乐插件根据返回总数、数组长度和成功映射数量判断。
旧插件未声明完整性时仍可普通导入，不能开启自动同步。

文件夹扫描不会忽略不可访问目录；已识别音频文件无法读取或没有可用解码器时，不会以空结果覆盖已有歌单。
所有来源读取串行执行，后台读取完成后在桌面 UI 上下文提交修改；同一歌单不会并发更新。
