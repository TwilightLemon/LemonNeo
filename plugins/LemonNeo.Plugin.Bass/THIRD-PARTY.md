# BASS third-party binaries

This plugin contains the following third-party binaries:

- BASS_FX by Arthur Aminov (JOBnik!), including SoundTouch by Olli Parviainen, for tempo and equalization on Windows, Linux, and macOS
- Bass.Net.dll 2.4.14.1
- bass.dll 2.4.16 for Windows x64 and x86
- bassflac.dll 2.4.5 for Windows x64 and x86
- bassmix.dll 2.4.13.1 for Windows x64 and x86
- basswasapi.dll 2.4.4.1 for Windows x64 and x86
- bassasio.dll 1.4.3 for Windows x64 and x86
- libbass.so and libbassflac.so for Linux x64, x86, ARM hard-float, and ARM64
- universal libbass.dylib and libbassflac.dylib for macOS x64 and ARM64

These binaries are isolated to the BASS plugin and are subject to their respective
licenses. [BASS](https://www.un4seen.com/bass.html),
[BASSASIO](https://www.un4seen.com/doc/bassasio/bassasio.html),
[BASS.NET](https://www.radio42.com/bass/bassnet.html)
