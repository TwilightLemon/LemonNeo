# BASS third-party binaries

This plugin contains the following binaries copied from the existing Lemon-App
resources supplied for this implementation:

- Bass.Net.dll 2.4.14.1
- bass.dll 2.4.16 for Windows x64 and x86
- bassflac.dll 2.4.5 for Windows x64 and x86

BASS and BASS.NET are third-party software. Redistribution and commercial use are
subject to their respective licenses from Un4seen Developments. These binaries
